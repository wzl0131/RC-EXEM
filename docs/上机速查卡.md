## ① 上电 30 秒：核对这 8 个（J-Scope 表格的 Value 列）

搜 `dbg_safety` → 勾这 8 个 → 看 Value

| 变量 | 正常 | 含义 |
|---|---|---|
| `dbg_safety_fault` | **0** | 当前故障码 |
| `dbg_safety_last_fault` | **0** | 上次复位前的故障码 |
| `dbg_safety_fault_pc` | **0** | 上次崩溃地址 |
| `dbg_safety_reset_reason` | **3** | 1=狗咬 2=软复位 **3=上电** 4=引脚 |
| `dbg_safety_reset_count` | **1** | 复位次数 |
| `dbg_safety_hb_ctrl` | **0~15** | 控制任务心跳年龄(ms) |
| `dbg_safety_hb_remote` | **0~30** | 遥控任务 |
| `dbg_safety_hb_debug` | **0~30** | 心跳任务 |

## ② 故障掩码（`dbg_safety_fault`）

```
bit0 =   1  遥控掉线          ┐
bit1 =   2  电调掉线          │ 第一层
bit2 =   4  电调报错误码       │ 只断电流
bit3 =   8  电机过温          ┘
────────────────────────────────
bit4 =  16  程序跑飞 (HardFault)
bit5 =  32  控制任务卡死       ┐
bit6 =  64  遥控任务卡死       │ 看门狗复位
bit7 = 128  心跳任务卡死       ┘
```

**多个同时有就加起来：**
```
 3 = 遥控+电调都掉      32 = 控制任务卡死
 5 = 遥控掉线+电调报错   48 = 32+16 卡死且崩过
```

## ③ 四阶段流程

```
A  上电核对 8 个变量         ✅ 全对才往下
B  跑 5 分钟不管它           reset_reason 一直=3 → 没被误咬
C  拔遥控→fault=1 / 拔CAN→fault=2 / 都拔→fault=3
D  ⭐ 加 while(1); → 0.5s 复位 → last_fault=32 / reason=1
      ⚠️ 测完必须删掉 while(1)！
```

**D 阶段的代码（加在 `freertos.c` 的 `StartControlTask` 里）：**
